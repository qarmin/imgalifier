# Third-party code

Vendored sources are copied into the repository (not forked as separate crates) and keep their original licenses. Improvements are made in place; every change of a vendored file should keep the original notice.

## heifer-hevc-dec 0.3.26 (MIT OR Apache-2.0)

- Origin: https://github.com/HarpeLm/Heifer (crates.io `heifer-hevc-dec` 0.3.26).
- Where: `crates/heif/src/hevc/{bitreader,cabac,contexts,decoder,filters,nal,params,recon,scan,sei,slice,syntax,testutil}.rs`.
- `hevc/mod.rs` and `hevc/hvcc.rs` are ours. The vendored `Error` type (originally `thiserror`) is hand-written in `mod.rs`.
- Used here under the MIT license.

## rav1d (BSD-2-Clause)

- Origin: https://github.com/memorysafety/rav1d, commit recorded in `crates/avif/src/rav1d/VENDORED_FROM`, license text in `crates/avif/src/rav1d/COPYING`. rav1d is a Rust port of dav1d (BSD-2-Clause, VideoLAN and dav1d authors).
- Where: `crates/avif/src/rav1d/` is generated by `scripts/vendor_rav1d.sh` (only `.rs` files, no asm, no C, `#[no_mangle]` C exports removed, crate paths rewritten, `libc`, `assert_matches` and `av-data` usages patched out). Do not edit those files by hand, change the script or re-run it against a newer checkout.
- Consequence: `imgalifier-avif` is licensed `MIT AND BSD-2-Clause` and requires edition 2021.
